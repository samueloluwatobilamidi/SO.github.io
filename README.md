# Samuel Oluwatobi — Data Analytics & Data Science Portfolio

Responsive static portfolio website built with HTML, CSS and JavaScript.

## Included
- 20 projects: 15 Excel/Power BI dashboards + 5 R data science case studies
- Category filter (All / Analytics / Data Science), with Platform + Domain filters for Analytics and a Method filter (Classification / Regression / Risk & Predictive) for Data Science
- Quick View modal: tech badges, insight summary, case-study progress indicator, "What this project demonstrates," and an interactive Model Comparison panel for each Data Science project
- Sticky navigation with scroll-spy active-section highlighting
- Mobile hamburger menu
- "Open to opportunities" status indicator
- Centered About section with profile photo and education
- Simplified, tag-based Skills presentation
- Fullscreen project viewer with keyboard (←/→/Esc) and previous/next navigation
- Lazy-loaded imagery throughout
- Reduced-motion accessibility support
- Single controlled glow accent system (hero + About photo)
- Email, LinkedIn, X and WhatsApp contact options
- CV download available only in the final Contact section
- Open Graph and X social-preview metadata
- GitHub Pages-ready static deployment

## Deployment
1. Upload the contents of this folder to the root of your public GitHub Pages repository.
2. Keep `index.html`, `style.css`, `script.js` and `assets/` at the repository root.
3. In GitHub, open **Settings → Pages → Deploy from a branch → main → /(root)** and save.
4. Open the published `github.io` address after deployment.

## Notes on Data Science project data
The 5 Data Science case studies show real charts from the most recent script run available, but the corrected R scripts have not yet been re-executed in this environment (no R runtime here). No metric numbers are displayed on the site — only techniques, chart images, and qualitative "what this demonstrates" summaries. See `Run_All_Data_Science_Projects.R` (provided separately) to regenerate fresh charts and metrics locally.
